# E-Warungku — Frontend

Aplikasi web manajemen warung & toko online (kasir POS, stok, pesanan + resi, laporan, invoice PDF, pengembalian dana).
Frontend statis (HTML/CSS/JS) untuk **GitHub Pages**; backend **Google Apps Script** sebagai REST API (data di Google Sheets).

```
index.html        halaman tunggal (SPA)
css/style.css     gaya
js/config.js      ← ISI GAS_URL di sini
js/api.js         komunikasi ke backend (fetch)
js/app.js         logika aplikasi
```

Cara pasang: lihat **PANDUAN-INSTALASI.md**. Backend (`Kode.gs`) tidak ada di repo ini — dipasang terpisah di Apps Script.
